📌 项目介绍

TG 桥接控制台 是一款完全基于 Cloudflare Worker 的 Telegram 消息桥接工具。

您无需购买服务器、无需部署后端代码，只需要一个 Cloudflare 账号即可实现：

  • 实时接收 Telegram 私密群组、公开群组、联系人私聊消息
  • 在网页控制台直接发送消息、发布到频道
  • 支持多群组、多联系人、多频道同时管理
  • 全球 CDN 加速，延迟极低

核心原理： Cloudflare Worker 接收 Telegram 的 Webhook 推送 → 转发到您的浏览器前端，同时支持从浏览器反向调用 Telegram Bot API 发送消息。

整个系统零服务器成本、零维护，安全可靠。

❓ 常见问题

Q：控制台无法接收消息，发送时提示“网络错误”，但 Telegram 里能看到机器人已经成功发出消息？

A：这是 Webhook 失效导致的典型问题。

解决方法：重新设置 Webhook

请在浏览器地址栏输入以下链接（把中括号内容替换成您的真实信息）：

https://api.telegram.org/bot【您的Bot Token】/setWebhook?url=【您的Worker地址】/webhook

访问后看到 {"ok":true} 即表示修复成功。
